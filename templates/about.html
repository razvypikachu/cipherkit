About CipherKit

A web-based cybersecurity toolkit built with Flask, designed for security enthusiasts and students.

LIGHTWEIGHT TOOLS
#
Hash Checker
Generate MD5, SHA256, and SHA512 hashes from any text input. Useful for verifying file integrity and understanding how hashing algorithms work.
⬛
Password Strength
Analyze password strength in real time based on length, complexity, and character variety. Also checks against the Have I Been Pwned database to see if the password has appeared in known data breaches.
⇌
Encoder / Decoder
Encode and decode text using Base64, Hex, and URL encoding. Commonly used in web security, CTF challenges, and data transmission.
ADVANCED TOOLS
◈
Nmap
Run network scans against a target host or IP. Discovers open ports, running services, and host information. Only use against systems you own or have permission to scan.
◎
Whois
Look up registration information for any domain — owner details, registrar, creation date, and nameservers.
